# TOOLFLOW — ระบบจัดการยืม–คืนอุปกรณ์ (Frontend Demo)

ตัวอย่าง Frontend สำหรับระบบยืม–คืนวัสดุอุปกรณ์ห้องปฏิบัติการ ออกแบบสำหรับสาธิตโปรเจกต์ โดยใช้ HTML, CSS, JavaScript และ SVG ที่สร้างจากโค้ดโดยตรง

## จุดที่ปรับในเวอร์ชันนี้

- UI โทนกรมท่า–น้ำเงิน–เทา–ขาว ปรับรูปแบบให้คล้ายแอปจัดการคลังและรองรับมือถือ, iPad และหน้าจอคอมพิวเตอร์
- เปลี่ยนอีโมจิในเมนูและปุ่มเป็นไอคอน SVG แบบเส้น
- ผังห้อง 2D/3D สร้างจาก SVG/JavaScript ไม่ใช้ภาพผังเป็นพื้นหลัง
- ผัง 3D เป็นมุมมองเปิดด้านบนและด้านหน้า ไม่มีผนังห้องมาบัง เห็นกรอบตู้ ชั้นวาง ชั้นวางย่อย และสัญลักษณ์อุปกรณ์ที่จัดเก็บอยู่
- คลิกตำแหน่งเพื่อกรองอุปกรณ์ที่เก็บอยู่ในตู้/ชั้นนั้น
- เจ้าหน้าที่เพิ่มและแก้ไขตำแหน่งจัดเก็บได้ ระบุพิกัด X/Y, ความกว้าง, ความลึก, ความสูง และจำนวนชั้นได้ ตำแหน่งที่เพิ่มจะแสดงในผังทั้ง 2D/3D
- เพิ่มอุปกรณ์ เลือกตำแหน่งและชั้น แก้ไขจำนวน สถานะชำรุด และแสดง QR สำหรับอุปกรณ์/ตำแหน่ง
- ฝั่งแอดมินเพิ่มบัญชีผู้ใช้และกรอกข้อมูลนักศึกษาได้ครบ ได้แก่ ชื่อ–สกุล, รหัสนักศึกษา, คณะ, สาขา, ชั้นปี, เบอร์โทรศัพท์ และอีเมล พร้อมกำหนดสิทธิ์
- หน้าเจ้าหน้าที่ตรวจคืนมีพื้นที่กล้องสแกน QR นักศึกษา แสดงข้อมูลนักศึกษาและรายการยืมค้างคืน พร้อมปุ่มยืนยันรับคืน
- มีตัวเลือกจำลองการสแกนเพื่อใช้เดโม่กรณีไม่มีสิทธิ์กล้องหรืออุปกรณ์กล้อง

## วิธีเปิด

1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `toolroom` ใน Visual Studio Code
3. ใช้ส่วนขยาย Live Server เปิด `index.html`
4. หากใช้กล้อง ให้เปิดผ่าน `localhost` หรือ HTTPS และอนุญาตสิทธิ์กล้องในเบราว์เซอร์

## หมายเหตุ

- เป็น Frontend Demo เท่านั้น ข้อมูลเก็บไว้ใน `localStorage` ของเบราว์เซอร์ที่ใช้งาน ยังไม่มี Backend/ฐานข้อมูลกลางหรือระบบยืนยันตัวตนที่ปลอดภัยสำหรับใช้งานจริง
- การสร้าง QR Code ใช้ไลบรารี QRCode.js ผ่าน CDN แบบโหลดภายหลัง ส่วนอ่าน QR ใช้ `BarcodeDetector` ของเบราว์เซอร์เมื่อรองรับ หรือ ZXing ผ่าน CDN หากไม่รองรับ หากไม่มีอินเทอร์เน็ต หน้าระบบยังเปิดได้และมี QR ตัวอย่าง/ปุ่มจำลองสแกนสำหรับการนำเสนอ
- ผัง 3D เป็นภาพฉาย isometric ที่วาดด้วย SVG และขนาดตำแหน่งเชิงสัดส่วนเพื่อการสาธิต ไม่ใช่โมเดล CAD ที่ยืนยันขนาดห้องจริง หากต้องใช้ในงานจริงควรวัดขนาดและปรับพิกัดให้ตรงกับห้อง
- บัญชีและข้อมูลทั้งหมดเป็นข้อมูลสมมติสำหรับการนำเสนอเท่านั้น


## อัปเดต UI เวอร์ชัน 1.3
- แถบเมนูกรมท่า ไอคอนและข้อความสีขาว
- นักศึกษาและเจ้าหน้าที่คลังใช้เลย์เอาต์มือถือขนาดไม่เกิน 440px แม้เปิดบนจอใหญ่ เพื่อให้เหมาะกับการใช้งานมือถือ
- ฝั่งแอดมินรองรับมือถือ แท็บเล็ต และเดสก์ท็อป พร้อมหน้าโปรไฟล์และปุ่มออกจากระบบ
- บล็อกอุปกรณ์รูปสี่เหลี่ยมพร้อมไอคอน SVG ตามชนิดอุปกรณ์ถูกวาดในผัง 3D จากโค้ด ไม่ใช้ภาพพื้นหลัง
- หลังเจ้าหน้าที่รับคืนครั้งแรกของนักศึกษา ระบบเปิดแบบประเมิน 5 ข้อ (คะแนน 1–5) และเก็บผลไว้ใน localStorage; สรุปผลแสดงในแดชบอร์ดแอดมิน
- บัญชีและข้อมูลยังเป็นข้อมูลเดโม่เก็บในเบราว์เซอร์ ไม่ใช่ระบบฐานข้อมูลกลาง


## อัปเดต UI เวอร์ชัน 1.4
- ปรับสัดส่วนแถบเมนูมือถือให้ไอคอนและชื่อเมนูมีระยะห่างสมดุล และกำหนดพื้นที่ด้านล่างให้เหมาะกับมือถือ
- ย่อการ์ดสรุป “ประเภทอุปกรณ์ / พร้อมให้ยืม / รายการค้างคืน” ของนักศึกษาให้เรียง 3 การ์ดในแถวเดียว และย่อการ์ดสรุปของเจ้าหน้าที่
- เพิ่มภาพประกอบอุปกรณ์ที่วาดด้วย SVG ตามชื่ออุปกรณ์ เช่น สว่าน หมวกนิรภัย คีม ประแจ ตลับเมตร และอุปกรณ์ไฟฟ้า แทนไอคอนกล่องแบบเดิม ไม่ต้องโหลดไฟล์ภาพจากภายนอก
- รายการอุปกรณ์ของนักศึกษาเปลี่ยนเป็นการ์ดที่อ่านง่ายบนมือถือ แสดงภาพ ชื่อ รหัส จุดจัดเก็บ หมวดหมู่ และจำนวนคงเหลือ
- เพิ่มตัวกรองหมวด “ทั้งหมด / อุปกรณ์ยืม–คืน / วัสดุสิ้นเปลือง” ในหน้าหลักนักศึกษาและหน้าจัดการอุปกรณ์เจ้าหน้าที่ พร้อมป้ายหมวดสีแยกกัน
- เพิ่มภาพประกอบในรายการตะกร้ายืม รายการอุปกรณ์ที่เลือกจากชั้นวาง ตารางคลังของเจ้าหน้าที่ และตารางภาพรวมคลังของแอดมิน


## อัปเดตเวอร์ชัน 1.5: ดาวน์โหลด QR สำหรับติดชั้นวาง

ในเมนูผู้ดูแลคลัง > **จัดการอุปกรณ์และตำแหน่ง** มีปุ่ม **ดาวน์โหลด** ที่การ์ดของแต่ละตู้/ชั้น และในหน้าต่าง QR มีปุ่ม **ดาวน์โหลด QR สำหรับพิมพ์ (PNG)**

ไฟล์ PNG เป็นฉลากพื้นขาวพร้อมหัว TOOLROOM, ชื่อชั้น/ตู้, รหัสตำแหน่ง และ QR ความละเอียดสูง ข้อมูลใน QR เป็น `LOCATION:<รหัสตำแหน่ง>` เช่น `LOCATION:A` เพื่อให้หน้าแสกนของนักศึกษารู้ว่ากำลังเลือกอุปกรณ์จากจุดจัดเก็บใด

หมายเหตุ: การสร้าง QR PNG ต้องโหลดไลบรารี QRCode.js จาก CDN จึงควรเชื่อมต่ออินเทอร์เน็ตขณะใช้งาน หาก CDN ใช้งานไม่ได้ ระบบจะแจ้งเตือนและจะไม่สร้างไฟล์ QR ปลอมให้พิมพ์


## อัปเดตเวอร์ชัน 1.6: ปุ่มจำลองประเมินความพึงพอใจ

- เพิ่มปุ่ม **จำลองประเมินความพึงพอใจ** ในหน้า **คืนอุปกรณ์** ของนักศึกษา เพื่อเปิดแบบประเมินได้ทันทีโดยไม่ต้องรอเจ้าหน้าที่ตรวจคืน เหมาะสำหรับสาธิตต่อกรรมการ
- การคืนอุปกรณ์ครั้งแรกยังเปิดแบบประเมินอัตโนมัติเหมือนเดิม
- เมื่อกดจำลองและบัญชีนั้นมีผลประเมินอยู่แล้ว การส่งผลจำลองจะอัปเดตคำตอบเดิมแทนการเพิ่มรายการซ้ำ
- ผลประเมินยังแสดงในแดชบอร์ดแอดมินเหมือนเดิม


## อัปเดตเวอร์ชัน 1.7: หน้าต่างรายละเอียดอุปกรณ์

- กดการ์ดอุปกรณ์ในหน้าแรกของนักศึกษาเพื่อเปิดป็อปอัพแสดงภาพประกอบอุปกรณ์ ชื่อ รหัส ประเภท ตำแหน่ง/ชั้นวาง จำนวนทั้งหมด จำนวนคงเหลือ จำนวนที่กำลังยืมหรือจ่ายออก และจำนวนชำรุด
- ฝั่งเจ้าหน้าที่กดชื่ออุปกรณ์หรือปุ่ม **รายละเอียด** ในตารางจัดการคลังเพื่อเปิดรายละเอียดชุดเดียวกัน
- ในป็อปอัพรายการอุปกรณ์ที่เปิดจาก QR ของชั้นวาง สามารถแตะชื่ออุปกรณ์เพื่อเปิดรายละเอียด และปิดกลับไปยังรายการชั้นวางเดิมได้
- ภาพอุปกรณ์เป็น SVG สร้างจากโค้ดในระบบ ไม่ต้องใช้ไฟล์ภาพภายนอก
- ฝั่งเจ้าหน้าที่/แอดมินมีปุ่มแก้ไขข้อมูลจากหน้ารายละเอียดอุปกรณ์


## อัปเดตเวอร์ชัน 1.8 — TOOLFLOW Branding
- เพิ่มโลโก้ TOOLFLOW จากไฟล์ที่ผู้ใช้ให้ในหน้าเข้าสู่ระบบ แถบเมนู และแถบหัวเรื่อง
- เพิ่มพื้นหลังลายเฟืองสีดำ/เงินแบบ SVG ลายน้ำจาง ๆ เพื่อสื่อถึงงานวิศวกรรมและคลัง โดยไม่ใช้ภาพตกแต่งขนาดใหญ่หรือบังเนื้อหา
- เน้นข้อความ “แตะตู้หรือวัตถุบนผังเพื่อเลือกดูตำแหน่งวัสดุ” ด้วยแถบสีน้ำเงินกรมที่มองเห็นชัดในหน้าแผนผัง
- โลโก้และลายเฟืองอยู่ใน `assets/img/` และผังห้องยังคงสร้างจาก SVG/JavaScript ไม่ได้ใช้ภาพผังเป็นพื้นหลัง
